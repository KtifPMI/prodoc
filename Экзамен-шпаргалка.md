# ПроДокторов — шпаргалка к зачёту (10 вопросов)

Развёрнутый ответ на вопросы к зачёту по системе ПроДокторов. Основано на базе знаний help.prodoctorov.ru и правилах платформы.

---

## 1. Основные сущности: ЛПУ, Доктор, Workplace

### Что такое ЛПУ
- **ЛПУ** (лечебно-профилактическое учреждение) — общее название медицинской организации: клиника, медицинский центр, больница, сеть клиник.
- На портале каждая ЛПУ представлена **страницей клиники**: название, адрес/гео, телефон, график работы, специальности, услуги, прайс, врачи, рейтинг и отзывы.
- У ЛПУ может быть **несколько адресов/филиалов** — это отдельные страницы одной сети.
- ЛПУ может состоять в **сети клиник** — тогда все филиалы управляются из одного личного кабинета (включение через поддержку, бесплатно).

### Основные сущности системы
- **Доктор (специалист)** — карточка врача со специальностями, местом работы, опытом, рейтингом, отзывами и расписанием.
- **Workplace (рабочее место/место работы)** — связка «врач + конкретное ЛПУ»: адрес приёма, специальность, цена первичного приёма, клубная скидка, онлайн-/телефонная запись. Один врач может иметь несколько workplaces в разных клиниках.
- **Пациент** — пользователь, авторизованный по номеру телефона (МедТочка).
- **Запись** — событие приёма пациента у врача в конкретном workplace.

### Мастер- и слейв-профили / мультилогин
- У клиники может быть **несколько страниц** (филиалов), управление — через сеть клиник.
- В личном кабинете клиники есть **мультилогин** (версии Стандарт/Профи): несколько пользователей с разными ролями.
  - **Суперпользователь** — все разделы + финансы + интеграции.
  - **Полный доступ** — все разделы без финансовых.
  - **Настраиваемый доступ** — отдельные права (отзывы, колл-центр, бухгалтерия, реклама).
- У врача «master/slave» в контексте платформы означает соотношение главного кабинета и привязанных рабочих мест (workplace): ведение профиля врач может передать клинике через доверительное управление (version ПО клиники Стандарт/Профи).

### Создание сущностей
- **Создание страницы клиники:** «Ваша страница?» → данные → заявление о присоединении с подписью и печатью → модерация до 24 часов.
- **Добавление нового ЛПУ в каталог:** «Добавить клинику в город N» → форма → модерация до 3 рабочих дней; при проблемах — help@medrocket.ru с фото фасада, номером лицензии, ссылкой на сайт.
- **Создание страницы врача:** врач находит свою страницу → «Это Вы?» → регистрация (email, телефон, портретное фото, скан диплома/сертификата/аккредитации) → модерация до суток.
- **Добавление врача в клинику:** «Добавить врача» (врач из другого города — только через поддержку). Удаление — «Удалить из клиники», возможно только при отсутствии врача на сайте клиники; страница отвязывается, а не удаляется, отзывы остаются на странице врача.
- **Добавление места работы врача (workplace):** ЛК врача → «Добавить адрес приёма или специальность»; сверка с официальным сайтом ЛПУ (закон о СМИ); при неактуальном сайте — документ с печатью. С 14.09.2026 появилась кнопка «Добавить место работы в другом городе».

## 2. Запись на приём: типы записи

### Типы записи на приём
Система поддерживает несколько каналов записи, которые настраиваются клиникой:

1. **Онлайн-запись (через МИС)** — пациент выбирает врача/услугу на портале, запись автоматически попадает в МИС клиники.
2. **Запись по телефону** — уникальный номер ПроДокторов; робот фиксирует этапы согласования даты/времени; запись создаёт администратор клиники.
3. **Клубная запись (запись по Клубной цене)** — онлайн-запись со скидкой от 30% по Клубу.
4. **Онлайн-консультация (телемед)** — запись на дистанционный приём (информационная или телемедицинская консультация).
5. **Экспресс-запись** — быстрый тип: выбор врача с уже готовым форматом приёма в один шаг «Записаться» (без долгого пути), чаще всего используется для услуг/диагностики и анализов.

### Отличительные черты типов (врач и услуги)
| Параметр | Онлайн-запись | По телефону | Клуб | Телемед | Экспресс |
|---|---|---|---|---|---|
| Слот нужен из МИС | Да | Нет | Да | Да | Да |
| Оплата с баланса клиники | Успешные записи | Записи по звонку | Сбор 10% | Успешные | Успешные |
| Неуспешные не оплачиваются | Да | Да | Да | Да | Да |
| Невозвратный платёж для пациента | Нет | Нет | 50% опцион | Нет | Нет |

### Создание каждого типа записи
- **Онлайн-запись:** ЛК клиники → «Записи на приём» → «Настройки» → «Хочу подключить» → выбор МИС → заявка → звонок менеджера. После подключения: «Врачи» → карандаш → «Запись включена» + цена первичного приёма + возраст пациента.
- **Запись по телефону:** «Записи на приём» → «Настройки» → «Хочу подключить» → контакты → «Жду звонка». График колл-центра меняется только через менеджера.
- **Клубная запись:** клиника вступает в Клуб (только при активной онлайн-записи) → указываются клубные скидки по врачам → пациентам становится доступна клубная цена.
- **Телемед:** «Врачи» → карандаш → «Запись включена» → цена в поле «Онлайн» по каждой специальности; интеграция настраивается в МедФлексе.
- **Экспресс/услуги:** привязка цен на услуги → услуга отображается в поиске услуг с кнопкой «Записаться».

### Условия доступности записи
- Онлайн-запись доступна, только если включена у ≥30% врачей и не меньше чем у трёх врачей.
- Нужен положительный лицензионный баланс, заполненная карточка врача, слоты в расписании, активная синхронизация МИС.

## 3. Клуб

### Что такое Клуб и клубная карта
- **Клуб** — программа лояльности ПроДокторов: пациенты получают скидку от 30% на консультацию у врача.
- **Клубная цена** — цена приёма со скидкой от 30%, доступная только для врачей клиник — участников Клуба.
- **Клубная карта/доступ:** вступление бесплатно на первые 6 месяцев; продление — 99 ₽ на следующие 6 месяцев, без автопродления.

### Жизненный цикл клубной записи со стороны пациента
1. Пациент находит врача с меткой Клуба (клубная цена + доступные ячейки).
2. Выбирает дату/время приёма (ячейку) как при обычной записи.
3. Авторизуется через МедТочку (удобный способ входа).
4. Указывает данные пациента, проверяет специальность врача.
5. Выбирает «Записаться и оплатить» по Клубной цене.
6. ОПЛАЧИВАЕТ ОНЛАЙН 50% клубной цены (опцион) в течение **20 минут** — иначе запись отменяется.
7. Получает **опцион об оплате** (в карточке записи в МедТочке и на указанный email) + чек.
8. В день визита показывает опцион в клинике и оплачивает оставшиеся 50%.
9. После использования доступ к Клубу действует 6 месяцев; далее платно (99 ₽/6 мес).

### Ключевые правила Клуба
- Оплаченные онлайн 50% — **невозвратны** (на этом условии клиника даёт скидку).
- Скидка действует только на консультацию врача; допуслуги (инъекции, биопсия и т.п.) оплачиваются отдельно.
- Перенос клубной записи — только через клинику (в МедТочке перенос недоступен).
- Отмена — аналогично через клинику.
- Проверять, того ли пациента записывают в семейном профиле (ошибка = возврат 50% невозможен).
- Опцион можно сохранить на смартфоне и показать в клинике без интернета.

### Выставление клубных скидок (для клиники)
1. Клиника подаёт заявку: ЛК → «Хочу вступить» (при активной онлайн-записи) → контакты → «Жду звонка».
2. Менеджер активирует Клуб после проверки.
3. После активации в разделе «Врачи» появляется поле **клубная скидка** для каждого врача.
4. В ЛК доступны: аналитика по записям из Клуба, отчёты по доходимости (статус «Явка» проставляется автоматически), список опционов.
5. Если пациент не явился — клиника возвращает 40% стоимости приёма.
- Клубная цена не используется для специальностей с «Бесплатным приёмом при условии лечения».

## 4. Механизм работы расписания, слоты

### Как устроено расписание
- Расписание врачей и прайс клиника **выгружает из МИС** («Хочу подключить» → выбор МИС → выгрузка расписания и прайса).
- Расписание может настраиваться на портале или через МедФлекс (интеграции).

### Что такое слот
- **Слот (ячейка)** — доступный интервал времени для записи к врачу в расписании.
- Онлайн-запись возможна только при наличии свободных слотов.
- Пациент выбирает «доступную ячейку в расписании врача» → переходит в форму записи.

### Проверка онлайн-записи (порядок действий)
Если «не работает онлайн-запись», проверяют по цепочке:
1. Заполнена ли карточка врача.
2. Есть ли слоты в расписании.
3. Активна ли синхронизация МИС.
4. Не нулевой ли баланс.
5. Кэш/техработы.

### Правила изменения записи (слоты)
- Отмена/перенос в МедТочке — только если до приёма больше **60 минут**.
- Перенос доступен на даты в пределах **30 дней**, одну запись переносить не более **3 раз**.
- Клубную запись перенести через МедТочку нельзя — только через клинику.
- Перенос услуги с направлением — только через клинику.

### Лимиты записи с одного номера
- ≤5 записей в сутки с одного номера телефона.
- На одного врача — 1 непрошедшая запись на семейный профиль.
- ≤3 непрошедших записей на услуги одного класса в одной клинике.
- ≤3 семейных профилей на врача/услугу.

### Влияние расписания на ранжирование
- **Свободные ячейки на 14 дней** — до 100 баллов врачу.
- **Доступность записи** (сколько часов в неделю открыта запись): 15 ч — 0, 16 ч — 8, 17 ч — 17, 18 ч — 25, 19 ч — 33, 20 ч — 42, 21 ч — 50 баллов.
- **Успешность онлайн-записей** за 30 дней: до 75% — 0 баллов, далее +4 балла за каждый процент.
- Цена первичного приёма из МИС — +10 баллов врачу.

## 5. Подтверждение номера телефона и авторизация

### Подтверждение номера телефона
Способы подтверждения/входа по номеру (варианты, реализованные в системе):
1. **Код из SMS** — на номер отправляется код подтверждения, который вводится в форму.
2. **Звонок / голосовое подтверждение** — код диктуется автоматическим звонком (если СМС не доходит).
3. **Подтверждение через email** — дополнительное подтверждение почты кодом (например, для отзывов; статус отзыва приходит на email).
4. **Вход через МедТочку / авторизованный номер** — номер уже авторизован в семейном профиле, дополнительный код не требуется.

### Авторизация как пациент
- Пациент авторизуется **по номеру телефона** (СМС-код или звонок).
- Все записи с портала, семейные профили, отзывы, анализы, опционы Клуба привязаны к МедТочке.
- При оставлении отзыва — вход через МедТочку.

### Авторизация как клиника/врач
- **Врач:** «Это Вы?» → email/пароль/телефон (СМС) → модерация до суток. Восстановление — «Забыли пароль?» (ссылка на email); при недоступной почте — поддержка (8 800 707-31-29 / help@medrocket.ru / doc@medrocket.ru).
- **Клиника:** «Ваша страница?» → должность, ФИО, email, пароль, телефон → SMS + подтверждение email → заявление о присоединении с подписью и печатью → модерация до 24 часов.
- Мультилогin клиники — роли пользователей (суперпользователь, полный доступ, настраиваемый).

## 6. Отзывы

### Жизненный цикл отзыва
1. Пациент нажимает «Оставить отзыв» → вход через МедТочку.
2. Заполнение: звёздные оценки → кто был на приёме → клиника, специальность, дата → текст → фото эффекта → подтверждающие документы.
3. **Проверка (4 этапа):**
   - Анализ текста ИИ во время написания.
   - Автоматическая проверка уникальности.
   - Модерация сотрудником (первичная и повторная).
   - Расширенная проверка с запросом документов.
4. **Публикация** — обычная модерация до 24 часов, расширенная до 10 дней; во время проверки отзыв временно скрыт.
5. **Дополнения** — до 3 дополнений на отзыв о враче (текст ≥200 символов), можно сменить оценку и прикрепить документы; новое дополнение поднимает отзыв вверх.
6. **Старение** — отзыв полностью устаревает через 15 лет.

### Категории отзывов по влиянию на рейтинг
- **Основные категории:**
  - Отзыв о враче.
  - Отзыв о клинике.
- **Система оценок (шаг изменения):**
  - Оценки по 5 критериям, где 1 — ужасно, 5 — отлично.
  - m (−2…+2) — диапазон, на который отзыв двигает рейтинг.
  - z (лёгкие = 1, обычные = 1,2) — вес по типу отзыва.
  - подробный отзыв влияет в 1,2 раза сильнее.
  - авторизованные r=3 (с 2019 не учитывается).
  - A/A1/A2 → шкала 0–5 (5 достижимо); до пересчёта диапазон −9,99…+9,99.
  - максимум рейтинга — 5 (наилучший); минимальное значение при пересчёте — −9,99.

### Дополнительные категории отзывов
- **Отзывы о лекарствах (ПроТаблетки)** — оценки по 3 критериям + текст; запрещены дозировки и схемы приёма; авторизация через ЛК ПроДокторов.
- **Отзывы гостей** (не подтвердивших номер) — на рейтинг не влияют (до 2019 года были учтены).
- **Отзывы через колл-центр** — собираются по звонку; на расширенную проверку не попадают (есть подтверждение записи); опубликовываются не позже 24 часов после звонка.
- **Отзывы с подтверждающими документами** — надёжнее, публикуются без задержек.

### Оставление отзыва в каждой категории
- **О враче:** оценки + текст «чем помог/не помог», врач оценивается как специалист.
- **О клинике:** аналогично, с акцентом на организацию приёма.
- **О лекарстве:** через раздел ПроТаблетки.
- Конструктор ответа на негатив/позитив — для врачей и клиник.

### Дополнения отзывов
- До 3 дополнений на отзыв о враче; **текст ≥200 символов**.
- Можно сменить оценку и прикрепить документы.
- Новые дополнения поднимают отзыв вверх.
- При новом приёме — новый отзыв с того же номера (не дополнение).

## 7. Спецразмещение

### Что это
- Платная услуга: карточка клиники или врача на первой странице каталога по специальности в городе.
- Действует **1 сутки** (00:00–24:00 МСК), не более 3 карточек на странице.
- На рейтинг и отзывы не влияет.

### Механизм аукциона (GSP — «вторая цена»)
- Распределение мест — **аукцион «второй цены» (Generalized Second Price)**.
- Победитель платит ставку следующего участника.
- Пример: ставки 105/100/95/80 ₽ → платят 100/95/80 ₽; ставка 80 ₽ не участвует и не списывается.
- Ставки принимаются до **23:00 МСК**, аукцион проходит 23:00–24:00.
- При равных ставках выше карточка с большим рейтингом.
- Есть «Повторять ежедневно» и «Рекомендуемые ставки» (ставка 1-го места прошлого аукциона + 1%).

### Варианты размещения
- Клиника ставит ставки за свою карточку и за карточки врачей.
- Есть размещение **по болезням** и в списках **услуг/диагностики** (нужна привязка услуги; если услуга перестала выгружаться из МИС — удалить ставку и создать заново).

### Финансы
- Списывается с **рекламного баланса** клиники.
- Требуется достаточный рекламный баланс.

## 8. Рекламные кампании

### Где настраивается
- Раздел ЛК клиники «Рекламные кампании» — здесь список текущих кампаний и добавление баннеров.

### Запуск новой кампании
- **Новый баннер** (впервые или новый дизайн) запускается **только через менеджера по рекламе** (контакты указаны в разделе).
- Если баннер ранее размещался или прошёл модерацию — кнопка «Добавить».

### Параметры кампании
- Город показа.
- Выбор баннера.
- Охват (зависит от размера баннера).
- Выбор специальности врачей (при настраиваемом охвате).
- Количество показов на пользователя (1–5 раз в сутки).
- Общее количество показов.
- Предпросмотр баннера; стоимость корректируется от параметров.
- Кнопка «Купить» → галочка о подтверждении достоверности информации → «Подтвердить».

### Правила
- Запуск — при достаточном рекламном балансе.
- **После запуска изменения невозможны** (закон №347-ФЗ).
- Таргетинг по тематике, географии, интересам; антифрод-фильтр от ботов.
- Показ засчитывается, только если 100% баннера находилось в активном окне ≥2 секунд.
- Оплачиваются только зачтённые показы.
- Новые баннеры — только через менеджера.

## 9. Кабинет клиники

### Основные разделы
- **Врачи** — управление списком врачей, карточками, специальностями, ценами, клубными скидками.
- **Записи на приём** — история записи, выгрузка расписания/прайса, запись по телефону, партнёрские сервисы.
- **Отзывы** — вкладки «о врачах» и «о клинике», ответы, приватный чат.
- **Аналитика** — просмотры, место в рейтинге, звонки, колл-центр, записи.
- **Рекламные кампании** — баннеры и спецразмещение.
- **Кошелёк/Финансовый отчёт** — балансы, акты, счета.
- **Виджеты** — код виджета ПроДокторов для сайта клиники.
- **Услуги и диагностика** — прайс и привязка цен.
- **Контент клиники** — график работы, изображения, видеовизитка, акции.

### Врачи
- Добавление: «Добавить врача»; врач из другого города — только через поддержку.
- Удаление: «Удалить из клиники» — только при отсутствии врача на сайте клиники; страница отвязывается, отзывы остаются.
- Редактирование параметров записи по каждой специальности: цена первичного приёма, клубная цена, «На дом»/«Онлайн», возраст пациента (верхняя граница невключительная).
- Доверительное управление профилями врачей (версии Стандарт/Профи).

### Версии ПО (лицензионный договор)
- **Лайт** — бесплатно: профиль, ответы на отзывы, виджеты, 1 пользователь.
- **Стандарт** — аналитика, акции, доверительное управление, несколько пользователей с ролями.
- **Профи** — всё + отключение рекламы конкурентов и блоков «Другие клиники/врачи города».
- **Ультима** — всё + брендированная страница, сквозная аналитика, выделение в списке клиник.
- Период — **30 календарных дней**, смена в **00:00 МСК**; автопродление списывается каждые 30 дней; при нехватке средств — переход на Лайт.
- С 07.09.2026 подключение списывается сразу; разница за неиспользованные дни возвращается бонусами на лицензионный счёт.

### История записи
- Вкладки: «Онлайн-запись», «Запись по телефону», «Все звонки».
- По каждой записи: номер телефона, дата и номер записи, информация о приёме, стоимость.
- Записи через Клуб — нулевая стоимость + отметка под номером телефона; статус отмены/переноса отображается там же.
- Запись по телефону: прослушивание/скачивание аудиозаписи, расшифровка (Стандарт/Профи).
- Поиск записи по номеру телефона, выгрузка отчёта, выборка периода.

### Отзывы
- Модерация до 24 ч (обычная) / до 10 дней (расширенная); постпроверка опубликованного ~10 дней.
- Ответы: вручную, конструктором (негатив/позитив) или ИИ.
- Приватный чат: «Решить проблему» (пациент может аннулировать любую оценку) или «Поблагодарить».
- Теги на странице клиники — из 10 самых частых тегов авторов (нужны ≥11 опубликованных отзывов).
- Клиника не может удалить отзыв (ПроДокторов — СМИ).

### Аналитика
- **По маркетингу** (Стандарт/Профи/Ультима): просмотры страницы клиники и врачей, место и рейтинг, звонки, длительность разговоров, эффективность колл-центра, записи; фильтры по периоду.
- **Сквозная аналитика** (Ультима): сопоставление расходов на ПроДокторов с чеками МИС; передаются id записи, дата/время, тип записи, стоимость записи и спецразмещения, телефон пациента.
- Лидогенерация: результаты в «Записях на приём» (пометка источника) и «Финансовом отчёте».

### Лицензионный договор
- Баланс **лицензионный**: оплата успешных записей (онлайн, по телефону, онлайн-консультации), версии ПО.
- Записи на услуги — 3,7% от стоимости (в пределах мин/макс по населённому пункту); Клуб — сервисный сбор 10% от клубной стоимости приёма; по телефону и онлайн-консультации — по тарифу города.
- Пополнение: по счёту юрлица (1–3 раб. дня) или онлайн картой/СБП (мгновенно, без закрывающих документов).
- Автопродление ПО каждые 30 дней; смена версии в 00:00 МСК.

### Рекламный договор
- Баланс **рекламный**: спецразмещение, баннеры.
- Средства лицензионного и рекламного балансов **не пересекаются**.
- Уведомления о низком балансе — по порогу по каждому договору, в VK и на почту (при сбое — SMS).

### Финансовый отчёт
- **Финансовый отчёт** — все списания по обеим договорам.
- **Акты** — PDF для бухгалтерии за расчётный период.
- **Счета** — статусы оплаты.
- Расчёт порога ухода в минус: с 26.05.2025 учитывается число дней с балансом >1000 ₽ за последние 30 дней; порог считает каждому договору отдельно, лимит обновляется 1 раз в сутки.

## 10. Кабинет пациента (МедТочка)

### Что такое МедТочка
- Личный кабинет пациента ПроДокторов: веб-версия и приложения (App Store / Google Play / RuStore).
- Авторизация по номеру телефона; все записи с портала отслеживаются там же.

### Разделы МедТочки
- **Ближайшие записи** — предстоящие приёмы, детали, перенос/отмена.
- **Запись на приём** — выбор врача/услуги/диагностики, выбор слота, оплата клубной цены.
- **Семейные профили** — данные пациентов (в т.ч. ребёнок/родственник), привязка к записям.
- **Отзывы** — статус, дополнение, документы.
- **Баланс/бонусы** — программа лояльности клиники: бонусы за запись через портал, оплата части приёма бонусами.
- **Онлайн-консультации** — чат/видеозвонок (чат открывается за 5 минут до начала).
- **Анализы** — заказ (например, KDL), статус, результаты; оплата в течение 20 минут, сдача в течение 14 дней.

### Правила отмены и переноса
- Отмена/перенос — только если до приёма больше **60 минут**.
- Перенос на даты в пределах **30 дней**; одну запись переносить не более **3 раз**.
- Клубную запись перенести нельзя (только через клинику).
- Онлайн-консультацию (телемед) отменить — не позднее чем за час (иначе только через клинику).

### Записи на услуги и анализы (экспресс-путь)
- Шаги: услуга → клиника → дата/время → авторизация → семейный профиль → «Записаться».
- С направлением: загрузка фото/скана (JPG, HEIC, PNG, PDF; ≤2 файлов, ≤16 Мб); направление видно клинике до приёма и 7 дней после; оригинал — на приём.

### Семейные профили и лимиты
- До 3 семейных профилей на врача/услугу; не более 5 записей в сутки с одного номера.
